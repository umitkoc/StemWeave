# Adım 1 — GitHub repo ve monorepo iskeleti

**Durum**: Tamamlandı

## Yapılanlar
- pnpm workspace ve Turborepo altyapısı oluşturuldu.
- `apps`, `services`, `packages` ve `infrastructure` klasörleri açıldı.
- TypeScript, ESLint ve Prettier ayarları tamamlandı.
- GitHub organizasyonu/repo hedefleri ayarlandı ve `origin` bağlandı.
- `CODEOWNERS`, Issue ve Pull Request şablonları eklendi.
- GitHub Actions CI workflow'ları kuruldu ve test edildi.
- `pnpm install --frozen-lockfile` yeteneği doğrulandı.

İlk commit yapılarak `main` dalına push'landı.
